# InkWell

InkWell is a full-stack web application for creating, viewing, and managing blog posts. The application is built using React for the frontend and Node.js with Express for the backend. It also uses MongoDB for data storage and Cloudinary for image uploads.

## Features

- User authentication (signup, login, logout)
- Create, update, and delete posts
- View posts by category
- Upvote posts
- User profile management
- Dark mode support

## Tech Stack

### Frontend

- React
- Redux Toolkit
- React Router
- Tailwind CSS
- Axios
- Vite

### Backend

- Node.js
- Express
- MongoDB
- Mongoose
- Cloudinary
- JWT for authentication

## Installation

### Prerequisites
